# KOLIANI — REGION CANON

## Regras gerais

- Os PNGs aprovados definem a direção visual das regiões.
- Este cânone textual é a autoridade para nomes, intervalos de níveis, bosses e notas de lore.
- Em caso de conflito entre texto presente num PNG e este documento, este documento prevalece.
- Boards regionais mais recentes e aprovadas prevalecem sobre roadmaps antigos.
- Imagens rejeitadas ou canceladas não fazem parte do cânone.
- A Região 01 não possui referência visual PNG nesta conversa.
